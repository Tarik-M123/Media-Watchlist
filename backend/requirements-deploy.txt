# Deployment requirements: requirements.txt without fastembed.
#
# fastembed pulls an ONNX runtime and downloads a 67 MB model on first use,
# which costs ~190 MB resident and a slow cold start. On a free tier with an
# ephemeral disk that download repeats every time the service wakes.
#
# Leaving it out is safe by design: embeddings.py imports fastembed lazily,
# inside _load(), and raises EmbeddingsUnavailable when it is missing. Both
# callers catch that, so the app runs and the assistant still answers factual
# questions — it only loses mood-based semantic matching.
#
# numpy is NOT optional: embeddings.py imports it at module level, and
# assistant.py and media_catalogue.py import embeddings at module level.
